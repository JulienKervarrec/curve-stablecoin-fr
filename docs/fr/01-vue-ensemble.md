# 1. Vue d’ensemble de Curve Stablecoin

Ce dépôt regroupe les contrats de crvUSD et de Llamalend. Le parcours suit le code Vyper, les scripts Python, les déploiements et les tests comme cartes de lecture, sans installer ni exécuter le projet.

Le système combine une monnaie stable, un marché de dette et un AMM spécialisé pour accompagner les positions proches de la liquidation. Les dossiers curve_stablecoin, deployments et tests donnent les trois angles essentiels : mécanismes, intégration et propriétés attendues.

La suite décrit d’abord LLAMMA, puis l’ouverture d’une dette, les oracles, les liquidations et les protections.
