# 7. Flashloans, callbacks et défense en profondeur

Le dépôt couvre les flashloans, les callbacks de coffre, la réentrance et les bornes d’émission. Les scénarios d’intégration examinent les chemins où un appel externe revient dans le protocole pendant une opération sensible.

La protection combine vérification d’état, limites de dette, permissions, conservation des intérêts et refus de configurations incohérentes.

Les règles de déploiement et scripts de revue sont des supports d’audit ; ils ne constituent pas une preuve d’exécution dans ce parcours.
